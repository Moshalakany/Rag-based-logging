LogRag — RAG-Based Log Intelligence System

Architecture Overview · .NET 8 API + Angular 17 UI + Ollama + Qdrant

Ingestion Pipeline

  • • FileLogSource: checkpoint-resume, multi-line event detection, BOM/CRLF handling
  • • Filter → Parse (5 strategies) → Normalize (SHA256 dedup) → ID Extract (UnionFind)
  • • SlidingWindowChunker (512/64 tokens) → Embed (Ollama, batch 16, 4 parallel)
  • • Upsert to Qdrant + 30-day retention cleanup

Query / Retrieval

  • • Dual-path: ID exact match + semantic vector search
  • • LogHash dedup, heuristic reranker (0.85×score + 0.15×lexical)
  • • ContextBuilder formats numbered chunks with metadata
  • • SSE streaming: meta → tokens → final (with citations)

Infrastructure

  • • .NET 8 Minimal API, Angular 17 Standalone
  • • Ollama: llama3.2 (LLM) + nomic-embed-text (768d)
  • • Qdrant: Cosine distance, 30-day retention
  • • Ingestion: daily batch (24h) or streaming poll (30s)
